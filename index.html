🛡️ GG Endpoint Hardening Auditor

Auditoria de configurações Windows por coleta PowerShell somente leitura.

Importar JSON de auditoria

Carregue um relatório produzido no seu próprio computador. Nenhum arquivo é enviado para servidores.

🚀 Como gerar seu JSON

  1. Baixe o script Collect-Hardening.ps1 e revise o conteúdo.
  2. Abra o Windows PowerShell em uma máquina Windows autorizada.
  3. Execute o comando abaixo, após ajustar o caminho se necessário:
& "$env:USERPROFILE\Downloads\Collect-Hardening.ps1" -OutputPath "$env:USERPROFILE\Downloads\gg-hardening-audit.json"
⬇ Baixar script

O script não modifica configurações. Se a execução for bloqueada por política, siga o procedimento aprovado pela sua equipe de TI; não desative controles de segurança. Consultas sem permissão serão registradas como não verificadas.

📁 Saída: Downloads\gg-hardening-audit.json. Depois selecione esse arquivo abaixo.

Privacidade: processamento local no navegador. Evite dados corporativos sensíveis em sites públicos; prefira implantação interna.

Como funciona?

1. Informe o cenário ou importe um arquivo autorizado.

2. Analise os resultados e sua confiabilidade.

3. Revise as recomendações antes de usar o PDF.

⚠️ Protótipo funcional para validação. Não é scanner completo nem solução homologada para produção.
