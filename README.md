# 🛡️ GG // Endpoint Hardening Auditor

Auditoria de configurações Windows por coleta PowerShell somente leitura.

🌐 **[Abrir interface web](https://geovanniandrade.github.io/gg-endpoint-hardening-auditor/)**

## Como funciona
Carregue um relatório produzido no seu próprio computador. Nenhum arquivo é enviado para servidores.

- Interface acessível em português, com exemplos didáticos e relatório via impressão/PDF.
- Sem backend: dados processados localmente pelo navegador.
- Protótipo inicial **não homologado para produção**; conferir precisão, segurança e permissões antes de uso corporativo.
- Nunca publique dados pessoais ou inventários corporativos confidenciais.

## Próximas etapas
Validação automatizada, testes com dados sintéticos, documentação de instalação local e aprimoramento da análise.
